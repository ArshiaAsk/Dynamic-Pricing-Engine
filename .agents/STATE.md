# STATE.md — Ground Truth for the Dynamic Pricing Engine

**Purpose:** This is the single source of truth about what *actually works* in this repo.
Read this **before** trusting `README.md`, `docs/*`, or any code comment/docstring.
Those are aspirational and, in several places, false.

**How this was produced:** Every claim below was verified by reading the actual source,
tracing imports, and (where possible) running the code against the real working-tree model
`models/demand_model.pkl`. Docs and comments were treated as *hypotheses only*.

**Artifact tracking:** `models/demand_model.pkl`, `reports/*.json|csv`, and
`data/features/*.parquet` are **gitignored** (`.gitignore:45,51,60-61`); they are regenerated
in the working tree by the training pipeline and are **not** committed. Only
`models/features.json` (the model's feature contract) is tracked. Where earlier text in this
file called the pickle "committed", read "present in the working tree". `mlflow.db` is likewise
**gitignored** as of D28 (2026-10-14, `.gitignore:80`) and is **not** committed — the registry's
state is machine-local. `.dockerignore` is **tracked** as of D29 (2026-10-15): its `.gitignore`
entry was removed (it sat at `.gitignore:73` before D29) and the file now excludes `.env`, so
build inputs live in git and local config is never baked into the image.
